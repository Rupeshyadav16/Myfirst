# 🗳️ Online Voting System

An Online Voting System developed to provide secure, efficient, and user-friendly digital voting. This project allows users to register, login, cast votes, and view voting results through an interactive web interface.

---

# 🚀 Features

✅ User Registration and Login  
✅ Secure Authentication System  
✅ Vote Casting Functionality  
✅ One Person One Vote System  
✅ Admin Dashboard  
✅ Real-Time Vote Counting  
✅ Result Display  
✅ Responsive User Interface

# ⚙️ Installation Steps

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/online-voting-system.git
```

---

## 2️⃣ Open Project

```bash
cd online-voting-system
```

---

## 3️⃣ Setup Database

- Open MySQL
- Create a database:
```sql
CREATE DATABASE voting_system;
```

- Import the SQL file into database

---

## 4️⃣ Configure Database Connection

Update database credentials in:

```bash
config.php
```

OR

```bash
.env
```

---

## 5️⃣ Run Project

### For PHP:
```bash
xampp -> htdocs -> start Apache & MySQL
```

### For Node.js:
```bash
npm install
npm start
```
